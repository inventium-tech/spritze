# AGENTS.md

> Machine execution rules for AI agents and automation. See CONTRIBUTING.md for human workflow.

## Project Structure

```text
.
├── src/                # library source (container, decorators, errors, token, public exports)
├── tests/              # bun test suite (di, factory, types, bench-report tests)
├── examples/           # runnable scripts importing directly from ../src/index.ts
├── bench/              # Bun micro-benchmarks (resolution throughput, container creation)
├── dist/               # generated build output (bun run build); not source
└── .github/workflows/  # CI pipeline definition
```

## Commands

All commands are non-interactive and safe to run in CI/automation contexts.

### Setup
```sh
bun install
```

### Code Quality
```sh
bun run typecheck        # tsc --noEmit, exit 0 on success
bun run typecheck:strict # stricter tsc pass (noUnusedLocals, etc.), exit 0 on success
bun run lint              # biome lint, exit 0 on success
bun run format:check      # biome format --check, exit 0 if already formatted
bun test                  # bun test runner, exit 0 on all tests passing
bun run check             # typecheck + typecheck:strict + lint + format:check + test, exit 0 on success
```

### Build / Run
```sh
bun run build        # bundle src/index.ts to dist/ via bun build, exit 0 on success
bun run build:types   # emit dist/index.d.ts via tsconfig.build.json, exit 0 on success
bun run prepack       # rm -rf dist && build && build:types, exit 0 on success
bun run examples      # run every script in examples/ sequentially, exit 0 if all pass
bun run bench         # full micro-benchmark run (bench/resolve.ts)
bun run bench:quick   # fast benchmark smoke test (used in CI)
```

## Constraints

- Do not modify files under: `dist/` (generated build output, regenerated by `bun run build`).
- Skip directories: `node_modules/`, `dist/`, `.git/`.
- No runtime dependencies are permitted in `src/`; the package must remain zero-dependency.
- Target runtime is Bun only — do not add Node.js- or browser-specific compatibility shims.

## Config Reference

CI pipeline (`.github/workflows/`) runs, in order: `bun install --frozen-lockfile`,
`typecheck`, `typecheck:strict`, `lint`, `format:check`, `test`, `examples`, `bench:quick`,
`prepack`, then verifies `dist/index.js` and `dist/index.d.ts` exist.
